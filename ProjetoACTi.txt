🚀 Desafio: Cadastro de Parceiros Comerciais 

Objetivo:
Criar um formulário com validações, máscaras, consumo de APIs externas e persistência no banco de dados via procedure, exibindo feedback visual ao usuário.📝

Campos obrigatórios do formulário:
Tipo de Parceiro (Agente Logística, Cliente, Despachante e Fornecedor)
Personalidade (Física/Jurídica )
Razão Social
Nome Fantasia
CNPJ/CPF
Segmento
Categoria
CEP 
País (default: Brasil)
UF 
Município
Logradouro
Número
Bairro
Email (validação de formato)
Telefone (com máscara)
Complemento
Celular
Observação

🔧 O que você precisa fazer?✅ Frontend (Angular ou outro framework moderno)
Criar formulário com todos os campos acima
Aplicar máscaras:
CNPJ/CPF 
CEP 
Tel/Cel 
Validações básicas:
Campos obrigatórios
Formato de e-mail válido
Mensagens de erro por campo inválido:
Mostrar mensagem abaixo do campo quando inválido (ex: "CNPJ inválido")
Feedback visual:
Destaque visual para campos com erro (ex: borda vermelha)
Exibir mensagem de sucesso ao cadastrar com sucesso
Exibir mensagem de erro ao falhar no envio

✅ Consumo de APIs externas:
Consulta de CNPJ (ReceitaWS ou similar)
Auto preenchimento de razão social
Consulta de CEP (ViaCEP ou similar)
Auto preenchimento de logradouro, UF, município e bairro

✅ Backend (C# .NET Core ou outro)
Criar API com rota POST /parceiros
Chamar procedure de inserção no banco (sp_inserir_parceiro)

✅ Banco de Dados (SQL Server ou outro)
Criar tabela Parceiros com todos os campos
Criar procedure de inserção segura, com tratamento de duplicidade, erros e validações básicas no banco

📦 Entrega deve conter:🎥 Vídeo demonstrativo (obrigatório):
Preenchimento do formulário
Máscaras e validações em funcionamento
Consumo de API para CEP/CNPJ
Feedback visual para erros e sucesso
Envio dos dados
Execução da procedure + SELECT * FROM Parceiros
